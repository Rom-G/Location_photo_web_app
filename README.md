# Ручное регрессионное тестирование веб-приложения «Location»

Проект ручного тестирования: регрессионный прогон веб-приложения по готовым тест-кейсам, ретест ранее зарегистрированных дефектов и регистрация новых баг-репортов, найденных в ходе прогона.

## Объект тестирования

Веб-приложение «Location» — сервис с карточками мест и профилем пользователя. Проверялись функционал редактирования профиля, работа с карточками мест и валидация форм на тестовом стенде.

## Объём работ

| Артефакт | Значение |
|---|---|
| Тест-кейсы (регресс) | 17 выполнено: 8 passed, 8 failed, 1 blocked |
| Ретест дефектов | 15 баг-репортов: 10 закрыты, 2 переоткрыты, 3 заблокированы |
| Новые дефекты | 7 зарегистрировано по итогам прогона |
| Всего в реестре | 22 дефекта, из них 10 закрыты |

## Ключевые дефекты

- **BR-006** (Блокирующий, переоткрыт) — после редактирования профиля новые данные не применяются: отображаются прежние значения.
- **BR-005** (Критический, переоткрыт) — не ставится отметка «Нравится»: иконка не меняет цвет, лайк не учитывается в счётчике.
- **BR-008, BR-009, BR-011** (Заблокированы) — функционал добавления и удаления карточек недоступен: кнопка «+» и иконка корзины отсутствуют на главной странице.
- **BR-020** (Высокий) — кнопка «Сохранить» остаётся активной при пустом поле «Имя».

## Что показало тестирование

- **Проблемная зона — сохранение профиля.** Дефект BR-006 прошёл цикл «исправлен → переоткрыт»: после фикса данные по-прежнему не применяются. Этот же дефект заблокировал кейс TC-17 (автоудаление пробелов при сохранении): проверить обрезку пробелов невозможно, пока не работает само сохранение.
- **Валидация реализована неполно.** Сообщения об ошибке при превышении лимита символов не отображаются (BR-018, BR-022), при этом кнопка «Сохранить» активна при пустом имени (BR-020) — введённые данные могут молча не сохраниться.
- **Ретест подтверждает 10 из 15 дефектов** как исправленные. Переоткрыты 2, ещё 3 заблокированы из-за отсутствующих элементов интерфейса — они не могут быть проверены до их восстановления.
